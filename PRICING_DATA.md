# Pricing Data

This file documents the sources used for the audit engine.

- Cursor pricing: https://www.cursor.so/pricing
- GitHub Copilot pricing: https://github.com/features/copilot#pricing
- Claude pricing: https://www.anthropic.com/pricing
- ChatGPT pricing: https://openai.com/chatgpt/pricing
- Anthropic API pricing: https://www.anthropic.com/pricing
- OpenAI API pricing: https://openai.com/pricing
- Gemini pricing: https://developers.generativeai.google/pricing
- Windsurf pricing: https://windsurf.ai/pricing

Each pricing point in `lib/pricing.ts` is anchored to the public plan names and monthly costs listed above.
